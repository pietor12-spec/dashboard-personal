# Dashboard Personal

App web privada (PWA) para el dashboard personal de patrimonio.

Este repositorio **no contiene ningún dato**: solo la pantalla de acceso. El dashboard y los datos viven en un repositorio privado y solo se descargan tras introducir la contraseña (el token de acceso está cifrado con AES-256-GCM + PBKDF2 600.000 iteraciones en `vault.json`).
